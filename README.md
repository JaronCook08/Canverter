# Canverter

> The most useful financial calculator you never knew you needed.

Canverter is a humorous web app that answers one of life's most important questions:

**"How many Monster Energy drinks, Red Bulls, or Costco hot dogs could I have bought instead?"**

Built as a web development project that doesn't take itself too seriously, Canverter combines a clean chat-style interface with entertaining conversions, random flavor selections, and tongue-in-cheek verdicts.

---

## Features

- 🟢 Monster Energy converter
- 🔵 Red Bull converter
- 🔴 Costco Hot Dog converter
- 🎲 Random drink flavors and hot dog toppings
- 💬 Unique intros and verdicts for every conversion
- 🎨 Dynamic themes that change with each converter
- 📱 Responsive design for desktop and mobile
- ⚡ Fast, lightweight, and dependency-free

---

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks. No libraries. Just plain web technologies.

---

## Why?

Canverter started because I wanted a fun project to practice web development while hopefully making a few people laugh.

What began as a joke turned into a fully featured web application complete with multiple pages, custom themes, responsive design, and enough personality to keep every calculation entertaining.
